Título: Creacion de tickets por usuarios que se registre.

Descripción: Este pequeño codigo nos permite crear automatimente un tickets del usuarios que se registra. El ticket tendra el Nombre, el Apellido, un option que elegira de modo radio y al fin el mensaje que escribe.

Requisitos: ¿Qué necesita tener instalado el usuario? Para poder usar esto code solamente nececitas un server que permitera ejecutarlo sin problema (ej: wamp, laragon, Xamp).
